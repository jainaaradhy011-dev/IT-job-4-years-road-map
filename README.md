# IT Job Roadmap: 4 Years to a High-Package Offer

A single-page website that lays out a four-year plan for landing a high-package IT job.

**Live website:** https://YOUR-USERNAME.github.io/it-job-roadmap/

## Features
- Year 1 to Year 4 roadmap with checklists
- Track selector: Web, AI, Data and Security
- Progress bar saved in the browser
- Package levels, free resources and common mistakes
- Light and dark themes, responsive on phone and desktop

## Run it locally
Open `index.html` in any browser. No install or build step is needed.

## Tech
Plain HTML, CSS and JavaScript in one file.

## Note
Package ranges are indicative and vary by company, city and year.
